Primordial Mass

Primordial Mass is a survival-horror roguelite with a focus on exploring an otherworldly and shifting environment.

Godot 2026

Project Description

The goal of Project 3 was to create an intermediate digital game prototype, while also individually working on a predefined weakness and to improve two strengths. I struggle with narrative design and choose to improve in coding as well as in 2D art. In the first week we started with discussing a theme for the project, resulting in “Illusions” as overall project theme. We then started to group up based on skill set and started research and the ideation process afterwards. The following weeks were then spent working on the project with each team member working on their tasks.

My Responsibilities:

Concept Art
I was in charge of creating 2D concept art for game assets such as items, currencies, the User Interface as well as objects like the portal. In addition to that I also experimented with the color palette for the main character and some enemies.
2D Art
For the game prototype I created 2D sprites like the title screen and Game Design Document. I also created the majority of the environment pixel textures, all User Interface elements except the scroll bar and most object sprites like the portal mentioned earlier.
Puzzle Design
I worked together with Hannes on puzzle designs, finalizing ideas and writing them so we had clear instruction on what and how to implement, as well as what the player might get from solving them and which variations might be possible.
Item design
Not only was I responsible for the visual concepts of the items, but also designed their purpose and functionality myself. For this, I created and established three classifications in addition to the currency, namely “usable”, “wearable” and “placeable”.
UML State Chart
For the enemies we decided that we want to focus on three different designs. After deciding on the “Globber”, the “Bunny” and the “Dragonfly”, I took initiative and wrote UML state charts for their behavior in game.
Narrative Design
I was mainly responsible for the Main Character profile and the corresponding mood-board. But also helped with the world design and the overall plot and premise.
