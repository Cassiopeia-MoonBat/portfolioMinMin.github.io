A Box Full of Cats

A puzzle game about arranging cats in a box. Originating out of a game jam at the "Jobs for future 2026" fair, Villingen-Schwenningen with the topic "1000 cats"

Unity 2026 2D Art

Project Description

A box full of cats is a small puzzle game prototype that was developed during a game jam. The goal of the game is to puzzle different types of cats into a cardboard box, filling it up. The cats have different shapes, sizes and behaviors. This infuences how they can be placed in the box.

The game core development for the prototype took part over 3 days within a team of 3-5 people. 3-5 due to the fact that one was only present during the first day, and another was solely present for the auditory development such as sound effects and game music. I personally was responible for all 2D art assets, including the cats, the box and background elements, as well as currenlty unused assets such as cat toys. Further development of the game is planned but currently on hold. This might include more cat types, a general overhaul of the artstyle as well as addon of the missing game mechanics such as cat dependencies and correlations.
